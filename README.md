# Fashion Store

Modern e-commerce fashion store built with Next.js 16, React 19, Tailwind CSS v4, Zustand, and Three.js 3D product visualization.

## Features

- **Product Catalog**: Filter by category, price, and search queries.
- **3D Visualization**: Interactive 3D preview using Three.js.
- **Cart & Checkout**: Persistent cart state with shipping and payment calculation.
- **Order Tracking**: Order history with status tracking.
- **Responsive Design**: Mobile-first UI with dark/light theme support.

## Getting Started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Build

```bash
npm run build
```
